# 🚗 Electric Vehicle Data Analysis Dashboard

## 📌 Overview
This project is an interactive Tableau dashboard built to analyze Electric Vehicle (EV) data and uncover key insights about adoption trends, market leaders, and distribution patterns.

---

## 📊 Key Insights
- Total EVs analyzed: **1.5L+ vehicles**
- **77.6%** of vehicles are Battery Electric Vehicles (BEV)
- Tesla dominates the EV market with the highest registrations
- EV adoption has grown rapidly in recent years
- Average electric range is **67.83 miles**

---

## 📈 Dashboard Features
- Top N Vehicles by Make (Dynamic Parameter)
- Year-wise EV Growth Analysis
- State-wise Distribution (Map Visualization)
- BEV vs PHEV Comparison
- CAFV Eligibility Breakdown
- KPI Cards for quick insights

---

## 🎯 Project Objective
The goal of this project is to analyze EV adoption trends and present insights using an interactive and user-friendly dashboard. It helps in understanding market dynamics, vehicle distribution, and growth patterns.

---

## 📂 Dataset Information
- Source: Washington State Department of Licensing (EV Population Data)
- Format: CSV
- Records: ~150,000 rows
- Key Fields:
  - Make  
  - Model  
  - Model Year  
  - Electric Vehicle Type  
  - Electric Range  
  - State  
  - CAFV Eligibility
